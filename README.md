# TravelMateAI ✦

**Your AI companion from touchdown to destination.**

TravelMateAI is an open-source airport transfer assistant for React Hyderabad Hack Day 2026. A traveller describes their journey in natural language; **Gemma 4** converts that request into structured travel intent, and the application uses that intent to recommend a suitable vehicle and drive a mock booking flow.

## Why AI is central

This is not a chatbot layered on top of a cab-booking UI.

The model is the **intent-understanding decision layer**:

~~~text
Traveller message
      ↓
    Gemma 4
      ↓
Structured travel intent (JSON)
      ↓
Vehicle recommendation engine
      ↓
Mock booking
~~~

Example request:

> I just landed at Hyderabad airport with my parents, 3 large suitcases and 2 cabin bags. We are going to Banjara Hills.

Gemma extracts structured data such as passengers, luggage, pickup and destination. The application then uses those values to recommend the vehicle class.

## Tech stack

- React + Vite
- Node.js + Express
- Google GenAI SDK
- **Gemma 4 26B MoE IT** (gemma-4-26b-a4b-it)
- Structured JSON output
- Mock vehicle recommendation + booking flow
- MIT License

Google's current Gemini API documentation supports structured JSON output using JSON Schema, and the supported-model list includes the Gemma 4 26B MoE IT model.

## Run locally

Requirements: Node.js 20+ and a Google AI Studio/Gemini API key with access to Gemma 4.

~~~bash
git clone https://github.com/VegirajuMahaveerVarma/StormBreakers.git
cd StormBreakers
npm install
cp .env.example .env
~~~

Add your key to .env:

~~~env
GEMINI_API_KEY=your_key_here
GEMMA_MODEL=gemma-4-26b-a4b-it
~~~

Then run:

~~~bash
npm run dev
~~~

Open http://localhost:5173.

### Demo without an API key

The UI includes a safe fallback mode so the complete product flow can be demonstrated before the API key is configured. For judging, configure the key so the live Gemma 4 response is visible.
